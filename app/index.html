    Settings

    Sync between devices

    Keep this journal the same on your phone and laptop by syncing through a private GitHub repository. Every sync is saved there as a commit, so the repository is also a full history of your pages.

    1. Create a private repository, for example paperleaf-data.
    2. Create a fine-grained token with access to only that repository and the permission Contents: Read and write.
    3. Enter both here, then do the same on your other device.

    The token is stored only on this device. Disconnecting stops syncing and leaves your pages and the repository as they are.

    Reading handwriting

    Paperleaf uses Claude Opus 5.5 to read photographed pages. It needs an Anthropic API key, which you can create at console.anthropic.com. The key is stored only on this device, and a photo is sent to Anthropic only when it’s being read.

    Accuracy

    After fixing a page’s text, tick “I’ve checked this text against the page”. Each checked page adds to this measure.
